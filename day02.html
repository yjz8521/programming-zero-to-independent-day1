Python 執行環境、Interpreter、REPL 與 Script

今天的成功標準不是寫出功能，而是能說清楚「程式碼由誰執行」，並知道 REPL 與 Script 各自適合什麼情境。

今天的學習證據

完成後，你應該能：

  • 確認 Python 是否真的可用
  • 分辨 REPL 與 Script
  • 保存環境問題的證據
20-Minute Rule先獨立嘗試 20 分鐘；需要 AI 時，預設只要求 Level 1 方向。環境問題不是能力失敗，先保存錯誤畫面。

今天先建立三個位置

Learning Objectives

  • 說明 Python language 與 interpreter 的差別。
  • 區分 REPL 與 script。
  • 用版本命令確認環境。

Prerequisites

  • 已完成 Day 1 的 File、Folder、Program、Terminal。
  • 能在檔案總管找到 repository。
  • 今天不要求先會 Python 語法。

New Terminology

Programming Language、Source Code、Interpreter、Compiler、Environment、REPL、Script。

先看懂執行流程

Source Code→Python Interpreter→執行結果

你寫下的文字不是硬體直接理解的指令；interpreter 會依 Python 的規則讀取、執行，最後產生結果或錯誤證據。

今天第一次操作

  1. 開啟 PowerShell。
  2. 輸入 python --version；若無法確認，再試 py --version。
  3. 成功後輸入 python 或 py，觀察 >>>。
  4. 輸入 exit()，確認回到 PowerShell。
看見失敗時不要猜安裝方式，也不要亂試陌生命令；保留完整錯誤文字，依正式教材的 Windows Python 附錄排查。
